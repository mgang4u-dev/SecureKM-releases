# SecureKM

**서버 접속 키를 암호화 금고에 보관하고, 필요할 때만 열어 쓰는 macOS 메뉴바 앱**

키 폴더를 압축 풀어 쓰고 다시 압축하는 걸 잊은 적이 있다면, SecureKM이 대신 챙겨요.
금고를 열어 둔 채 잊어도 정한 시간이 지나면 알아서 닫혀요.

## 주요 기능

- **AES-256 암호화 금고** — macOS 표준 암호화 디스크 이미지라 디스크에는 항상 암호문만 남아요
- **Touch ID로 열기** — 비밀번호는 키체인에 보관
- **자동 잠금** — 메뉴바에 남은 시간 표시, 닫히기 1분 전 알림에서 바로 연장
- **자리를 비우면 닫기** — 잠자기·화면 잠금 시 즉시 닫아요
- **세대별 백업** — 바뀐 내용이 있을 때 암호화 백업, USB·NAS 같은 추가 경로에도 사본
- **안전한 자동 업데이트** — 개발자 서명과 Apple 공증을 확인한 뒤에만 설치

## 다운로드

[**최신 릴리스**](https://git.mgang.app/mgang4u/SecureKM-releases/releases/latest)에서 DMG 파일을 받으세요.

## 설치

1. DMG를 열고 `SecureKM.app`을 `Applications`로 드래그
2. 실행하면 메뉴바에 자물쇠 아이콘이 나타나요
3. 시작 화면에서 **새 금고 만들기** — 쓰던 키 폴더를 바로 가져올 수 있어요 (권한 600 자동 정리). 가져온 원본은 암호화되지 않은 채 남으니 완료 화면의 **원본 지우기…**로 지우세요

## 사용법

메뉴바 자물쇠 → **금고 열기**(Touch ID) → `/Volumes/SecureKM`에 열려요.

> 잠겨 있을 때 자물쇠 아이콘을 누르면 바로 Touch ID가 떠요. 열고 나면 쓰던 앱으로 돌아가요. 패널은 우클릭으로 열어요. (설정 → 일반 → **아이콘을 누르면 바로 열기**에서 끌 수 있어요)
> Dock에 SecureKM을 고정해 두면 Dock 아이콘을 눌러도 똑같이 열려요.

`~/.ssh/config` 예시:

```
Host prod-web
    HostName 10.0.1.12
    User ubuntu
    IdentityFile /Volumes/SecureKM/prod-web.pem
```

- 금고가 닫혀 있으면 ssh가 키를 찾지 못해요. 메뉴바에서 연 뒤 접속하세요.
- 접속한 뒤 금고가 닫혀도 **이미 연결된 세션은 끊기지 않아요.**

## 백업과 복원

- 금고를 닫을 때 바뀐 내용이 있으면 `~/Library/Application Support/SecureKM/Backups`에 백업해요.
- 백업 파일(`SecureKM-backup-날짜.dmg`)은 **금고와 같은 비밀번호로 암호화된 DMG**예요.
- 설정에서 추가 백업 경로(USB, NAS, iCloud Drive 등)를 지정할 수 있어요. 연결이 끊긴 동안 밀린 백업은 다시 연결되면 자동으로 복사돼요.

**앱 없이 복원하기** — 앱이 망가지거나 지워져도 괜찮아요.

1. 백업 DMG(또는 금고 파일 `Vault.sparsebundle`)를 더블클릭
2. 금고 비밀번호 입력
3. 열린 볼륨에서 파일을 꺼내 쓰기

> ⚠️ 비밀번호를 잊으면 금고와 백업 모두 열 수 없어요. 비밀번호 관리자나 종이에 따로 적어 두세요.

## 삭제하기

설정 → 일반 → **SecureKM 제거…**를 쓰세요. Touch ID(또는 맥 암호)로 한 번 더 확인한 뒤, 앱과 함께 설정, 키체인에 저장한 비밀번호, 로그인 항목까지 정리하고 종료해요.

- 금고와 백업은 기본으로 **남겨요.** 다시 설치하면 그대로 이어 쓰고, 앱 없이도 더블클릭해서 열 수 있어요.
- **금고와 백업도 지우기**를 켜면 함께 휴지통으로 옮겨요. 그 전에 **최신 백업 저장…**으로 백업 하나를 다른 곳에 남겨 두세요.
- 모두 휴지통으로 옮기기만 해서, 휴지통을 비우기 전까지는 되살릴 수 있어요.

앱을 휴지통으로 바로 끌어다 버려도 안전해요. 금고와 백업은 암호화돼 있고, 평문 키는 남지 않아요. 남은 것을 직접 지우려면:

| 항목 | 위치 |
|---|---|
| 금고·백업 | `~/Library/Application Support/SecureKM` |
| 설정 | `~/Library/Preferences/com.mgang4u.securekm.plist` |
| 비밀번호 | 키체인 접근 앱에서 `com.mgang4u.securekm` 검색 |

## 요구 사항

- macOS 14 (Sonoma) 이상
- Apple Silicon (arm64)
